常见问题

是免费的吗？

是的，App 免费且完全开源。翻译需要你自备一个大模型服务的 API 密钥（部分服务，如智谱 GLM，提供免费额度）。

支持哪些翻译引擎？

DeepSeek、智谱 GLM、通义千问、Kimi，以及可自定义接口地址的通用对话端点（兼容 Chat Completions 或 Messages 请求格式，用于自部署或第三方部署的模型）。可在「设置」中选择。

在哪里填写 API 密钥？

打开 App 的「设置」，选择你的服务商，粘贴密钥。密钥仅保存在你的设备上，仅在翻译时发送给该服务商。

如何获取一个免费的密钥？

可先在智谱开放平台（bigmodel.cn）注册并创建 API Key，其部分模型提供免费额度，适合先试用。也可使用 DeepSeek、通义千问、Kimi 等其他国内服务，或填写自定义接口。

可以翻译什么？

  • 网页 —— 双语对照：原文段落下方紧跟译文。
  • YouTube 等视频 —— 双语字幕：原文在上，译文在下。

如何开启？

在 Safari 设置中启用扩展，然后用页面上的悬浮按钮（或视频播放器内的按钮）开始翻译。

你们会收集我的数据吗？

不会。详见隐私政策。我们没有运营任何服务器，不收集任何数据。
