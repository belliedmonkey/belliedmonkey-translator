隐私政策

大肚猴翻译（中国版）· 最后更新 2026 年 7 月 11 日

一句话：我们不收集、存储、出售或分享你的任何数据。本 App 没有我们运营的服务器——你的数据无处可去。项目完全开源。

1. 我们收集的信息

无。大肚猴翻译没有后端服务器、没有账号系统、没有统计分析、没有广告或追踪 SDK。开发者不会收到任何关于你或你使用情况的信息。

2. 本机存储的数据

以下内容仅保存在你的设备上（浏览器扩展存储），绝不上传给我们：

  • 你的设置（所选翻译服务、目标语言、显示选项）。
  • 你填写的 API 密钥（如所选服务需要）。它仅保存在你的设备上，仅在翻译时发送给该服务商。
  • 一份会自动过期的翻译缓存（避免对同一文本重复翻译）。

卸载 App 或清除扩展存储，即可删除以上全部数据。

3. 第三方翻译服务

翻译时，你选中的文本会经 HTTPS 从你的设备直接发送给你所选择的翻译服务商，并使用你自己的 API 密钥（如适用）。我们不参与该连接，也看不到这些文本。

文本按你所选服务商的隐私政策处理。本 App 支持以下国内大模型服务，以及可自定义接口的通用对话端点：

  • DeepSeek 深度求索
  • 智谱 GLM
  • 通义千问（阿里云百炼）
  • Kimi（月之暗面）
  • 自定义端点 —— 你可填写任意兼容 Chat Completions 或 Messages 请求格式的接口地址（用于自部署或第三方部署的模型）。此时文本按你所填接口对应服务方的政策处理。

请查阅你所使用服务商的隐私政策。你可随时在设置中更换或移除服务商。

4. 无追踪

我们不做跨 App／网站追踪，不建广告画像，不使用第三方统计。

5. 儿童

本 App 适合所有年龄使用，且不向任何人（包括儿童）收集数据。

6. 政策变更

若本政策变更，我们会更新页面顶部的日期。因项目开源，其完整历史公开可查。

7. 联系方式

如有疑问，请邮件 belliedmonkey@gmail.com，或在 GitHub 提交 issue。
