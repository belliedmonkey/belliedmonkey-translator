# 评测协议

本协议约束以后的测量怎么记。它不产生分数。质量、延迟、成本在有授权冻结集之前全部 **待测**。`eval/baselines/inventory.json` 的 `measurement` 必须保持 `none`，`thresholds` 必须保持空数组，`compositeScore` 必须保持 null。检查器锁这三件事。

## 运行器现在能做什么

`node eval/baselines/check.js`：

- 每个证据摘录仍能在指定文件里找到
- 每个形态 × 每个阶段恰好一格
- 样本目录为空，工具夹具被拒绝
- README 仍链到本索引和历史水位
- 基线文档没有把未测结果写成已经通过

它不调用模型，不读音频，不计算 COMET、CER、时延或费用。

质量运行器要等 `samples.json` 出现授权记录，并按形态写下冻结集版本之后再做。在那之前加一个会打印分数的空壳，不算基建完成。

## 一次将来的运行要钉什么

每次记录单独成目录，至少包含：

- git 修订与 `package.json` 版本
- flavor：`global` 或 `china`
- 平台：扩展 / iOS / macOS，以及听写臂 `sa` 或 `e1_b1`
- provider id、模型字符串、端点形状。不记录 key
- 提示词钉：`P_CORRECT`、`P_SEG_PROMPT`、`P_PAGE` 或 `P_OCR` 中实际发出的那条，加上该文件的哈希
- 路由：`conv-model-seg`、`conv-legacy-pass`、`subtitle-pass`、`page-translate`、`caption-translate`、`doc-text`、`doc-ocr` 之一
- 冻结集版本。没有版本就不得记成基线结果

非确定性（采样、流式修订）要写进同一次记录，而不是事后补一句「大概稳定」。

## 分阶段归因

阶段基线用来解释端到端失败，不能代替用户看见的结果。

同一次样本按顺序留下能拿到的中间结果：音频是否保留、ASR 文本、修正后的 `T:`（若走了那条路）、译文、呈现时间戳。上游缺了，端到端数字就标成「不能归因」，而不是猜是哪一段的错。

级联只做对照，不做加权总分。例如：ASR 文本已经错，而译文相对这句错文本是忠实的，记两行，不合成一个分。

## 质量

每个形态用自己的用户可见维度，二元通过/失败，加上从这条样本读出来的失败方式。维度见各形态文档。

不设统一阈值。建议阈值要单独列出、标明样本量，并保持未生效，直到人工裁定。

LLM judge 若以后使用，必须先有人工金标，报告 TPR 与 TNR，few-shot 和调参集不得接触最终冻结集。在那之前 judge 不是验收。本批没有 judge。

## 延迟

按形态记分布（至少 n、p50、p90），不设截止线。

| 形态 | 要记的时刻 |
|---|---|
| `realtime-listen` | 开口到首个上屏结果；到稳定定稿；修订次数 |
| `realtime-subtitles` | 同上，再加结果相对播放时钟的偏移 |
| 网页文字 | 视口单元从占位到译文或失败 |
| 预制媒体 | 播放位置到对应句译文就绪；长内容后段是否变慢 |
| 文档 | 打开到该页文字就绪；若走 OCR，识图结束与翻译结束分开 |

历史水位写「听译延迟文档目标有、线上统一遥测未出数」。那句话仍然有效。本协议没有新的延迟数字。

## 成本

能记到的再记：请求次数、供应商返回的用量、或当时费率下的估算。估算要写公式。没有请求就不写 0 美元冒充已测。免费额度路径与自带 key 路径分开记。本批成本 **待测**。

## 回归

- 冻结集不因为分数不好看而改写
- 改集 = 新 `setVersion`
- 路由、提示词、默认模型或听写臂变了，旧数字标成不可比，不覆盖
- 历史水位文件不改数字。新协议的结果写在本目录的运行记录里，本批还没有运行记录

## 环境

本批检查在开发机用 Node 跑 `eval/baselines/check.js`，不需要浏览器、模拟器、密钥或网络。这只证明契约检查能复现。它不证明任一形态的翻译质量。
