# 1.16.0 发布说明（**GitHub Release / 更新日志用这一份**）

> 这一份描述**整个版本**，每条行内标明是哪个面。生成器把每一行变成一个列表项，所以不要用分组标题。

## 国际版 · zh-Hans

```
· App（iPhone / iPad / Mac）与浏览器扩展 · 新：复习有了「今天来过就算数」—— 每 5 张一组，做完就是一个小终点；没有到期卡的日子也算来过，页面上看得到你连着来了几天。
· App（iPhone / iPad / Mac）· 改进：第一屏只说一件事 —— 翻译用哪个模型，你说了算。只想要网页翻译的，第一屏就有一条直达的路。
· App（iPhone / iPad / Mac）· 改进：设置里的「句子解析」改名为「翻译与句子解析」—— 它就是 App 里所有翻译用的那个引擎，文案现在这么说了。
· App 与浏览器扩展 · 新：一键配置多了「自定义」—— 有自己的 OpenAI 兼容接口地址，也能在这张卡上一次配好。
· App（Mac）· 修复：实时字幕听不到声音时，会分清「真的没有声音」和「拿不到系统声音（可能没开权限）」，并给一条去系统设置的路 —— 也不用再等 30 秒才知道。
```

## 国际版 · en-US

```
· App (iPhone / iPad / Mac) & browser extension · New: Review now counts showing up — five cards make a group, finishing one is a real stopping point, and days with nothing due still count. You can see how many days in a row you have come back.
· App (iPhone / iPad / Mac) · Improved: The first screen says one thing — you pick the model that translates. If you only want web page translation, there is a direct path right there.
· App (iPhone / iPad / Mac) · Improved: “Sentence notes” in Settings is now “Translation & sentence notes” — it is the engine every translation in the app uses, and the wording finally says so.
· App & browser extension · New: One-key setup has a “Custom” option — your own OpenAI-compatible endpoint can be set up from that card too.
· App (Mac) · Fixed: When live subtitles hear nothing, they now tell apart “really no sound” from “cannot get system audio (the permission may be off)”, with a way to open System Settings — and you no longer wait 30 seconds to find out.
```
