# 1.15.0 发布说明 · macOS（国际版 15 份 + 中国版）

> 与 iOS 那份同一组功能（引导、继续设置卡、设置里找回扩展提示、地址 / Key 提前指出），macOS 上都存在，所以文案相同。中国版同样不提免费额度。
> 用法：`node scripts/asc.js notes com.belliedmonkeytranslator MAC_OS 1.15.0 store-assets/release-notes-1.15.0-macos.md`

## 国际版 · zh-Hans

```
· 新：第一次打开的引导更短了 —— 登录提到第 2 屏，登录后自动领一份免费额度，接着当场翻一句、听一句，最后才去打开浏览器扩展。
· 新：「以后再设置」只关这一次 —— 下次打开，首页有一张「继续设置」卡，从上次停下的地方接着来。
· 新：点过「我已打开」但扩展其实还没开？到「设置 › 功能 › Safari 扩展」把首页那张提示找回来。
· 改进：接口地址只填了主机名、或官方平台没填 Key，离开输入框或点「测试」时就直接指出，不再先发请求再报一个看不懂的错。
```

## 国际版 · en-US

```
· New: A shorter first-run guide — sign-in moves up to the second screen, signing in sets up free credit automatically, then you translate and hear a sentence right there; turning on the browser extension comes last.
· New: “Set this up later” now means later, not never — next time, a “Finish setting up” card on the home screen picks up where you left off.
· New: Tapped “I've turned it on” but the extension isn’t actually on? Bring the home-screen tip back from Settings › Features › Safari extension.
· Improved: An endpoint with only a host name, or a missing key for a built-in provider, is pointed out as soon as you leave the field or tap Test — instead of sending a request and showing a cryptic error.
```
