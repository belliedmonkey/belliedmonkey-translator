# 1.17.0 发布说明 · iOS（国际版 15 份 + 中国版）

> 主角只有一个：评分触发点（PR #453，画布 `design/rating-moments/` 三轮裁定）。
> 译文末尾那行不再要评分，改成「去复习」；App 的评分请求挪到收获时刻，走系统 `requestReview`。
> iOS 的收获时刻不含 Mac 快速翻译（那句只在 macOS 的那一份里）。
> 用法：`node scripts/asc.js notes com.belliedmonkeytranslator IOS 1.17.0 store-assets/release-notes-1.17.0-ios.md`

## 国际版 · zh-Hans

```
· 改进：译文末尾那行不再请你评分，改成了「今天读过的句子，去 App 里复习 →」—— 一键回到 App 的复习。而且只在你真的连用了几天之后才出现，每天至多一次。
· 改进：评分请求挪到真正的收获时刻 —— 一组复习做完、听译或实时字幕结束有句子、系统翻译收件箱有新句子，由系统自带的评分弹窗来问，我们不再自己画一个。
```

## 国际版 · en-US

```
· Improved: The line under translations no longer asks for a store rating. It now reads "Review the sentences you read today →" and takes you straight back to review — and it only appears after you have really used it a few days running, at most once a day.
· Improved: Rating requests now happen at moments you actually got something — a review group finished, a live-translation or live-subtitle session that captured sentences, new sentences in the system-translation inbox — asked by the system's own prompt, never a custom popup.
```

## 国际版 · zh-Hant

```

· 改進：評分請求挪到真正的收穫時刻 —— 一組複習做完、聽譯或即時字幕結束有句子、系統翻譯收件匣有新句子，由系統內建的評分視窗來問，我們不再自己畫一個。
```

## 国际版 · ja

```
· 改善：訳文の下の一行はストア評価を求めなくなりました。「今日読んだ文をアプリで復習 →」に変わり、タップひとつで復習画面に戻れます。しかも数日続けて使ったあとにしか現れず、1日に多くて1回です。

## 国际版 · ko

```
· 개선: 번역 아래 줄이 더 이상 스토어 평점을 요청하지 않습니다. "오늘 읽은 문장, 앱에서 복습하기 →"로 바뀌어 한 번의 탭으로 복습 화면으로 돌아갑니다. 며칠 연속으로 실제로 사용한 뒤에만 나타나며 하루 최대 한 번입니다.
· 개선: 평점 요청을 실제로 성과가 있는 순간으로 옮겼습니다 — 복습 그룹 완료, 음성 번역·실시간 자막 세션에서 문장을 받았을 때, 시스템 번역 수신함에 새 문장이 도착했을 때. 시스템 기본 평점 창이 물어봅니다. 자체 팝업은 만들지 않습니다.
```

## 国际版 · de-DE

```
· Verbessert: Die Zeile unter Übersetzungen fragt nicht mehr nach einer Store-Bewertung. Sie heißt jetzt „Die Sätze von heute im Review wiederholen →“ und bringt dich mit einem Tipp zurück in die Wiederholung — und erscheint nur, wenn du sie wirklich an mehreren Tagen in Folge genutzt hast, höchstens einmal pro Tag.
· Verbessert: Bewertungsanfragen gibt es nur noch in echten Erfolgsmomenten — eine Wiederholungsgruppe geschafft, eine Live-Übersetzungs- oder Untertitel-Sitzung mit Sätzen, neue Sätze im Posteingang der Systemübersetzung. Gefragt wird über den Systemdialog, nie über ein eigenes Popup.
```

## 国际版 · fr-FR

```
· Amélioré : La ligne sous les traductions ne demande plus de noter l'app. Elle dit désormais « Réviser les phrases lues aujourd'hui → » et vous ramène en un geste à la révision — et elle n'apparaît qu'après plusieurs jours d'utilisation réelle, au plus une fois par jour.

## 国际版 · es-ES

```
· Mejorado: La línea bajo las traducciones ya no pide una valoración de la tienda. Ahora dice «Repasa las frases que leíste hoy →» y te lleva de vuelta al repaso con un toque — y solo aparece después de usarla de verdad varios días seguidos, como mucho una vez al día.

```
