# 1.23.3 发布说明（intl / CN × iOS / Mac + Chrome）

> 这一版把 1.23.2-intl 已经上架的用户可见面合回 main，并带上 BEL-197 / 198 / 199 / 212。
> 本版不声称听译已经完成；听译仍在持续改进。中国版仍只带境内引擎。

---

## 国际版 · iOS / macOS

```
· 合回 1.23.2-intl 已上架的用户可见面：泰语语音识别（Grok）与只留在本机的 Key、字幕台与分屏字幕布局、Duo 首页卡片。
· 默认浏览器引导更清楚：首次启用时能直接看到如何把 Safari 设为默认浏览器。
· Mac 窗口宽度 ≥720 时，登录页与设置页采用桌面布局；首次启用、文档与播客页面也使用宽窗布局。
· 设置侧栏的「完成」回到首页。
· 听译仍在持续改进；这一版不声称已经完成。
```

## 中国版 · iOS / macOS

```
· 合回 1.23.2-intl 已上架的用户可见面：字幕台与分屏字幕布局、Duo 首页卡片。
· Mac 窗口宽度 ≥720 时，登录页与设置页采用桌面布局；首次启用、文档与播客页面也使用宽窗布局。
· 设置侧栏的「完成」回到首页。
· 中国版仍只带境内引擎；泰语 Grok 识别不在中国版包内。
· 听译仍在持续改进；这一版不声称已经完成。
```

## Chrome（Chrome Web Store）

```
· 与 1.23.3 同一份源码构建；默认浏览器引导与设置侧栏「完成」回到首页。
· 中国版 Chrome 包仍只带境内引擎。
· 本步只构建 ZIP，不上传、不提审。
```
