# 1.9.0 发布说明（国际版 11 份 + 中国版 1 份 · iOS 与 macOS 同文）

> 这一版的主角是**免费额度**（PR #220）：登录即可领一份我们出的额度（约 0.2 美元，够翻几百页），
> 翻译、朗读、转写都能用；用完可以填自己的 key 继续，或加入社群。**国际版**才有这份代领额度；
> **中国版**改为在设置里指引用户去领**阿里云百炼自己的**免费额度（不经我们的手）。
> 顺带修了引导页一处：填完 key 点「继续」不再可能把 key 丢掉；并把浅色下的次要文字调得更清楚。
> 商店文案里不点名具体服务商（注册表是唯一登记处），只说「免费额度 / 你配置的 key」。
