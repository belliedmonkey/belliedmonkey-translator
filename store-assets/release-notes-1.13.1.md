# 1.13.1 发布说明（补丁版 · **Chrome 商店 / Firefox 商店 / GitHub Release / 更新日志用这一份**）

> 1.13.0 提审前的全回归（2026-09-19）在 Windows 虚拟机上查出 #345：「译」开着而 YouTube 视频还停在 0 时，8 次取字幕耗光、锁在「字幕不可用」，之后按播放也不恢复（#325 的同类，线上 1.12.1 同样）。用户裁定「先修」，修在 #346。
> 扩展两店、GitHub、两站的 1.13.0 当晚已发，所以这三面的 1.13.1 只说这一条。
> **Apple 四线没有发过 1.13.0（build 已挂、未提审），直接提 1.13.1**：macOS 用 `release-notes-1.13.1-macos.md`、iOS 用 `release-notes-1.13.1-ios.md`，那两份是 1.13.0 的全部内容 + 这一条。

## 国际版 · zh-Hans

```
· 修复：YouTube 视频还没开始播放时就打开字幕翻译，不再锁在「字幕不可用」；开始播放后字幕正常出现。
```
