# 社区帖草稿（只起草，不代发）

发送键一律由人点（见 memory `social-posts-manual-send-only`）。每份文件顶部写了去处、
最佳发帖时间和该社区的规则要点。发之前跑一遍 `node scripts/store-stats.js`，
把「多少国家 / 多少下载」的数字换成当天的，别用草稿里的。

文案红线（memory `oss-marketing-direction`）：
- 不说「iPhone Safari 上唯一 / 第一」—— Immersive Translate 有自己的 iOS 条目
- 不说「读过的句子变复习卡」是首创 —— Readlang / Trancy 在同一条线上
- 不说「完全免费」不加限定 —— 工具免费，LLM 翻译由用户自己的 key 付费
- 竞品全名可以出现在帖子里，绝不能进 App Store keywords
