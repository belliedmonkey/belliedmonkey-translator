# Code of Conduct

This project is small and mostly asynchronous — issues, discussions, pull requests — and it
works because people are direct without being unkind.

**Expected.** Be specific and be respectful. Report what you saw, on which version and which
surface (Safari on iPhone, Chrome, the Mac app…). Disagree with the idea, not the person.
Assume the other side is busy, not hostile. Chinese and English are both welcome.

**Not accepted.** Personal attacks, harassment, discriminatory language, publishing someone's
private information, and sustained disruption of a discussion. Sexualised language or imagery
has no place here.

**Scope.** Everything under this repository — issues, discussions, pull requests, commit
messages — and any place you represent the project.

**Enforcement.** Report a problem to belliedmonkey@gmail.com; reports are read by the
maintainer and kept confidential. Depending on severity the response is a private note, a
public warning, or removal from the project's spaces. Decisions are explained, not just applied.

Adapted in spirit from the Contributor Covenant, shortened to what a project of this size needs.
