半配好的四种样子

用户原话：「用户甚至不知道怎么样才算配置完成」。凡是「看起来配了、其实没成」的状态，都要说出差在哪、给一个出口。
填了没保存最常见。输入框是 change 触发，没失焦就没保存 —— 而界面此刻什么都不说。

还差一下

key 填在框里，但还没保存 —— 这个框是「改完自动存」，你点一下别处就好。

API Key未保存
保存了但 key 是错的自检红着。文案逐字复用既有的 auth_err_key，不另写。

保存了，但用不了

翻译✗ 服务商拒绝了这把 key（401）
解析跟随翻译
朗读未配置
这把 key 服务商不认。检查有没有多复制一个空格，或换一把。
领额度但没登录成功额度要登录才领得到；登录页在另一处，回来之后这里要自己变。

额度还没到

免费额度要先登录才领得到 —— 登录只用来认人，不同步任何内容。

免费额度未登录
选了免费引擎却仍显示未配置现存 bug，板上标红。

选了免费引擎，却说没配

选了不需要 key 的引擎之后，界面仍显示「还没配过翻译引擎」。

engineChosen 在 App 里一处都没写

这是现存的 bug，不是交互问题：判据 EngineState.needsSetup 要读这个键，而它只在扩展的两处被写过。

共同的判据：任何一处说「配好了」之前，必须有一次真的成功。没跑过自检就不说这句话 —— 这与「只信回读，不信没报错」是同一条。
