1 · 客户端与三条出口

同一份源码、两个构建 flavor（`node build.js [--flavor china]`）。**免费路径永远在**：自带 key、浏览器/设备 → 提供方直连， 一个字节都不经过我们的服务端。

浏览器扩展（Safari / Chrome / Edge / Firefox）

  • 网页双语 · YouTube 双语字幕 · 文档翻译 · 复习库
  • 两个 flavor 产物：dist/（global）· dist-china/（中国版，品牌无关，合规门把关）
  • 免登录即可用；账号与同步免费

App（iOS / macOS，同一棵 Xcode 树）

  • 复习 · 播客 · 实时听译/字幕 · 文档
  • 登录是前提（2026-10-01 裁定，issue #532）：引擎随登录到账、两个设备包要下到本机
  • 扩展侧**不受影响**：仍然免登录、自带 key 可用

4 · App 首屏三段式（#532）

**就绪 = 登录 ∧ 引擎可解析 ∧ 识别语言包 ∧ 朗读包**；不含 Safari 扩展（扩展是屏 3 里的一步，不是门）。 两个设备包按**设备引擎**探与下 —— 与当前默认选了哪个引擎无关（登录即领额度会把默认引擎指向服务端那条）。

屏 1 · 登录
硬门
只有登录：Apple / Google / 邮箱
无设置 · 无功能入口 · 无横幅
→
屏 2 · 资源包
硬门 · 无跳过
识别包（系统资产）· 朗读包（离线模型）
进度 · 失败具名 · 换地址重试
→
屏 3 · 引导
可跳过
welcome → firstuse → ext
→
首页

屏 2 → LearnTTS.ensureDeviceReady('device')

→ 原生逐文件下载 + sha256 → Application Support/mt-speech/

global 默认 GitHub Releases、备用已改 hf-mirror（国内可达）；china 默认 ModelScope、备用 hf-mirror。

模拟器装不了系统识别资产 ⇒ 屏 3 只能在真机上验（真机实测 15 s 到「已就绪」）。

5 · 数据边界（写在代码与文案里的承诺）

原文

中继只转发，**不落盘**；日志只有 relay <hash前8位> chat 200 …

台账

账号级、只记令牌 hash 与花费；与遥测**永不 join**

遥测

匿名白名单事件（global）；**中国版一个字节都不发**

第三方媒体

只存指针（media id + 起止），不存字节

用户自产语音

默认不上传；选择上传才计数、可一键删

配额

50 MB/账号，数据库约束强制，到顶明说、不静默丢
