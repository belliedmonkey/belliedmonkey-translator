## 0. 一句话

**Duo 内屏展开时，实时字幕主形态＝系统分屏：一半是别的视频 App，一半是本 App 字幕台。**  
本 App **不自建播放器**；普通 iPhone / Duo 外屏 **继续** 一期「外放 + 画中画」。

---

## 1. 为什么改

现货：App 内开始 → 切走外放 → 看 PiP 浮窗。Duo 大内屏上浪费空间，且模拟器无系统 PiP、演示证不了「边看边读」。  
用户要：**展开后一眼能同时看到视频和字幕**。一期用系统分屏旁挂达成，不绑 App 内嵌播。

---

## 2. 已裁方案

| 项 | 定案 |
| --- | --- |
| 视频半栏 | **B · 系统分屏旁挂**（YT / 浏览器 / 播客等任意视频 App） |
| 字幕半栏 | 本 App 独占分屏中的半屏，做「字幕台」 |
| 听源（一期） | **沿用现货**：麦听设备外放声（与 PiP 一期相同）；二期屏幕录制另挂，不挡本期 |
| 不做 | **A** App 内嵌播（本期不上）；**C** 假双栏占位（不上线） |

## 3. 并存与迁移（与现货 iPhone PiP 一期）

| 设备姿态 | 实时字幕主形态 | 画中画 |
| --- | --- | --- |
| **compact**（普通 iPhone；Duo **外屏**） | **不变**：准备页「先开始→外放→PiP」；预览 4:5 | 离开 App 自动浮出；✕＝暂停听 |
| **dualRegular / 分屏半宽**（Duo **内屏展开**且与视频 App 分屏；或其它 regular 半宽） | **新主形态**：本 App 整面＝字幕台；对面＝系统里的视频 App | 用户**离开本 App 且未保持分屏**时，仍可浮 PiP（降级，语义同 compact） |
| **半折 / 帐篷** | 本方案不绑；仍既有 P1（字幕半折放大） | — |

迁移原则：

1. **一套** `ListenSession` / `captionState` 跨姿态连续；展开↔外屏↔分屏不丢句、不重开听。  
2. compact 文案与 Pencil Duo-04 **保留**；展开/分屏新增 Duo-09。  
3. 用户在展开态尚未分屏时：本 App 全宽先显示字幕台 + **明确 CTA**「在分屏另一半打开视频」（禁止纯黑无字）。  
4. 合上外屏 / 退出分屏：收回 compact 预览语义；进行中离开 App → PiP。  
5. **不强迫** compact 用户学分屏；两套路径文案分姿态写清。

## 4. 本 App「字幕台」版式（B · 我们只占半屏）

### 4.1 信息架构（半宽优化）

本 App 在分屏半宽内 **整面** 都是字幕台（没有 App 内左视频栏）：

1. **顶**：返回 ·「实时字幕」· 听译中计时  
2. **主字幕面**（固定深色）：译文大字上、原文小字下；半句斜体+省略号；可显示最近 1–2 句  
3. **语言行**：`视频语言 → 译成`（语义不改）  
4. **最近句子**（可滚，半宽下列表）  
5. **底**：暂停 / 停止（✕/暂停语义与现货一致）

未进入分屏、但已是 dualRegular 全宽时：同一套字幕台居中或偏一侧均可，**上方或侧旁**放分屏引导条（见 §4.3），不要画假视频窗冒充「半视频」。

### 4.2 亮暗

- **页壳**（导航、语言、按钮、引导条）：跟随系统亮/暗。  
- **主字幕面**：固定深色（与悬浮条 / PiP 一致）。  
- Pencil：亮壳 + 暗壳各一列；字幕面旁注「固定深色」。

### 4.3 文案（展开 / 分屏态）

- **主引导（未分屏）**：「在分屏另一半打开视频或浏览器播放；这边看字幕。也可离开 App，字幕浮在画中画。」  
- **已分屏进行中**：弱化 PiP 句；强调「对面播、这边读」。  
- **compact 准备页**：**保留**「先点开始，再去任意 App 外放；字幕浮在画中画」（一字不废）。

### 4.4 明确不做（本期）

- 不在本 App 内嵌视频播放器 / 内嵌浏览器播片（A）。  
- 不要求双系统 PiP。  
- 不改「对话 · 实时听译」左控右史双栏。  
- 不把二期屏幕录制塞进本期。  
- **不挡**当前 1.21.0 已 TF 包提审闸；本形态由产品挂档/定波次。

## 5. 架构需核（交互提问，非代裁）

请架构师书面回：

1. Duo / iOS 上「与视频 App 系统分屏」的可检测与布局：`LayoutContext` / scene 几何在 Split View、Stage Manager 下如何映射到「半宽字幕台」。  
2. 听源一期继续麦听外放，在分屏同屏播视频时是否有回声/焦点坑；要不要壳层音频会话约束。  
3. 退出分屏 → 回 compact / 全宽时，与 `subtitle-pip` 降级的时序（何时允许浮 PiP）。  
4. 模拟器能否稳定演示「半屏本 App + 半屏占位/第二 scene」；若不能，验收用何种替身（见 §6）。

## 6. 验收（交互 · 结论交质量）

**不依赖系统 PiP** 即可证的：

1. **AC-DP1** dualRegular / 半宽：本 App 字幕台完整可读（主字幕面 + 暂停/停止）；未分屏时分屏引导 CTA 可见，非纯黑。  
2. **AC-DP2** 亮/暗壳：页壳跟系统；主字幕面仍深色。  
3. **AC-DP3** 展开↔外屏（或退出分屏）：caption 连续；compact 预览 / PiP ✕＝暂停听 与基线一致。  
4. **AC-DP4** compact 回归：准备页仍只指导外放+PiP；不出现「必须分屏」误导。

**真机 / 可分屏环境补：**

5. **AC-DP5** 本 App 与视频 App 系统分屏：一眼同时见视频与字幕；听译进行中对面播片有字。  
6. **AC-DP6** 结束分屏后离开 App：PiP 降级仍符合 compact 语义。

模拟器若无法开第二 App：AC-DP5 记 **need-device**；AC-DP1–4 不得因此跳过。
