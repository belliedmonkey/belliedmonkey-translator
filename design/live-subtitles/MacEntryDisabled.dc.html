门没过时整行灰（45%），下面一行写原因，并给一条直达设置的路。三种原因互斥，按顺序判；转写引擎是「设备内置转写」且可用时，① ② 不拦。

① 没有带实时接口的转写引擎

「实时字幕」需要一个带实时接口的转写引擎　去设置里选择 →

② 转写引擎没填 key
实时字幕给正在播放的视频、直播、会议配双语字幕

转写引擎还没填 API Key　去设置里填写 →
