# N24v2 下载中进度 · 交互补丁（2026-10-24）

**来源**：用户 TF 截图 t145u「这种情况看不到下载进度」  
**对照**：IA「下载中 · xx%」；N24v2 packs-dl 提示词 D-02「芯片小百分比或一行总进度」；像素稿 BEL-26 只锁了选语言/撞限/清理，**未锁下载中帧** → 现网落成「列表 + CTA 下载中」，无进度可视。

## 问题（现网）

1. CTA 仅文案「下载中」，无百分比 / 进度条 / 动画进度感。
2. 语言行只显示「已就绪」或空，看不出哪一门/哪块资源在下、下了多少。
3. 「识别最多 5 门」常显、「下载内容详情」折叠入口仍占位——下载态应让进度抢主视线。

## 改法（结构优先，同波可落地）

### D-02 下载中（补像素）

| 位 | 规则 |
| --- | --- |
| 标题 / lede | 保持锁文：`正在下载` / `可以切到后台，下完再回来` |
| 主进度 | **一行总进度**：左侧细进度条 + 右侧 `37% · 约 185 MB`（数字随实下更新；未知大小用不确定条 +「下载中」） |
| 明细（可选展开） | 默认收起；展开后按任务行：`听译基础` / `English` 等，行右 `xx%` 或 `已就绪`；未勾语言不出现 |
| 芯片/勾选 | 下载中**锁死不可改**；已就绪语言可保留勾选样式，但无「进度行」 |
| CTA | 禁用；文案改为 **`下载中 37%`**（与总进度同数），或保留「下载中」但主进度必须在 CTA 上方可见 |
| 砍掉/降权 | 下载态**不**常显「识别最多 5 门」；「下载内容详情」改为「进度详情 ▸」或并入总进度展开，勿再开第二套详情叙事 |
| 失败 | 总进度变红字一行 + CTA「重试」；单任务失败行内「重试」 |

### 不做

- 不为每门语言画满屏粗进度条（N24v2 已否）。
- 不改 lede 硬锁文案。
- 不在本补丁重开选语言 IA（D-01 像素已 PASS）。

## 验收

- [ ] 下载任一字节后，用户不读文案也能看出「还在下、大概到哪」。
- [ ] 后台返回再进屏，进度数字与实下一致（或不确定条仍在动）。
- [ ] 下载中改选语言不可行（锁勾选）。
- [ ] 亮/暗两套。
