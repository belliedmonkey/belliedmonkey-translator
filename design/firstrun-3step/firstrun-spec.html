首屏与首次使用流程 · 一页规格

大肚猴翻译 · App（iPhone / iPad / Mac）。三段序列：屏 1 登录（硬门） → 屏 2 资源包（硬门，无跳过） → 屏 3 引导（可跳过）。就绪 = 登录 ∧ 引擎可解析 ∧ 识别语言包 ∧ 朗读包，不含 Safari 扩展。中国版与国际版逐条同构，只有引擎来源不同。

对应画布：firstrun-canvas.html　·　可点击原型：firstrun-prototype.html

1 · 判定顺序（唯一入口函数）

boot() {
  if (!isLoggedIn)              return Screen1_Login;      // 硬门：这一屏只有登录
  if (!engineResolvable())      return Screen1_Login;      // 引擎不通（如额度用尽且无自带 Key）→ 同一屏，不新造一屏
  if (!asrPackInstalled() || !ttsPackInstalled())
                                return Screen2_Packs;      // 硬门：无跳过
  if (!onboardingSeen())        return Screen3_Onboarding;  // 软门：可跳过，不阻塞
                                return Home;               // 已登录 + 已就绪 ⇒ 直进
}

// 降级：系统不支持该语种识别时，唯一允许绕过 Screen2 的情形
degrade(asrUnsupported) { enableTtsOnly(); Home(state: notReady) }

老用户已登录、但缺包时走的是 TopUp（补齐屏），不是 Screen2 的三段重来：登录已成立、无需再登录、无需重放引导。

5 · 六条红线与判据

每条给出「怎么判红」——可直接落成 UI 断言、快照比对或文案 lint。

红线 1未登录首屏只有登录

判据：在 !isLoggedIn 下渲染 S1，屏内可见的可点击元素集合必须 ⊆ {Apple, Google, 邮箱}，且页面上 不存在「设置」「复习」「对话/字幕/文档」任何入口词；实心按钮数 == 1。

判红：出现任一非登录入口，或出现 0 个 / 2 个以上实心按钮，或出现指向 S2/S3/Home 的导航。

红线 2屏序可达，且屏 2 无跳过、屏 3 有跳过

判据：可达性 = 从冷启动出发，S1→S2→S3→Home 每一步都有正向触发路径；S2 的可见文案与可及性节点中不出现「跳过 / 稍后 / 先用着 / skip」；S3 的三态均存在可点击的「跳过引导」且跳过后 onboardingSeen = true、直接落 Home。

判红：S2 出现任何跳过出口（即使灰色、即使二次确认）；或 S3 无跳过；或跳过 S3 后仍回到 S3 / 停在中间态。

红线 3就绪判据 = 引擎 + 识别包 + 朗读包，不含扩展

判据：就绪函数的可观测输入只有 {isLoggedIn, engineResolvable, asrInstalled, ttsInstalled}；对 16 种布尔组合逐一断言：任一项为假 ⇒ 不可进 Home(ready)；四项全真 ⇒ 必进 Home(ready)。Safari 扩展状态不出现在该函数签名、S2 完成摘要或放行判断中。

判红：扩展未开却判为就绪；或只差一个包却放行；或就绪函数读取了扩展开关。

红线 4两个 flavor 逐条同构

判据：同一 locale 下分别以 flavor = cn / intl 渲染全流程，做 DOM 快照对比：节点数、文案串、按钮顺序、状态分支数必须完全一致；允许的差异仅限白名单（出境同意勾选条、额度来源行「境内中继 / 通义千问」、引擎标识）。

判红：差异超出白名单，或某个 flavor 多出/少一屏、多一种失败分支。

红线 5旧承诺不得复活

判据：对 App 侧所有可见字符串跑否定式文案 lint，禁止匹配 不登录也能|无需登录即可|不用登录也|登录后不影响使用|游客可用 等模式；同一 lint 在扩展侧允许命中（需标注 scope = extension）。所有出现「登录」的说明句必须与硬门一致：App 需要登录。

判红：App 字符串集中出现上述任一模式；或出现「完整使用」与硬门冲突的组合表述。

红线 6每屏至多一个填色按钮 · 对比度 AA · 文案可落 12 语种

判据：(a) 每屏 background === accent-press 的实心按钮计数 ≤ 1；(b) 全部文本/图标对底色对比度：正文 ≥ 4.5:1、大字与图标 ≥ 3:1，hover/focus/active 状态不得低于默认值，禁用态是唯一例外；(c) 每个新文案落在已定义的文案槽位表内，且在 320pt 宽下不折行超过 2 行，超长先改句子后改字号。

判红：出现第二个实心按钮；hover 时前景变灰；浅底浅字或深底深字；新增文案未登记槽位。
