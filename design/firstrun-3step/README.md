## 这次改版的六条裁定（画布与规格都按它生成）

1. **首屏三段式**：屏 1 登录（**硬门**）→ 屏 2 资源包（**硬门，无跳过**）→ 屏 3 引导（**可跳过**）。
2. **中国版与国际版逐条同构**，只有引擎来源不同（境内中继 · 通义千问）。
3. **就绪 = 登录 ∧ 引擎可解析 ∧ 识别语言包 ∧ 朗读包**，**不含 Safari 扩展**。
4. **App 的前提是登录**（不登录不能用）；**浏览器扩展不受影响**（免登录、自带 key）。
5. 免费额度随登录**自动到账**，不问、不勾。
6. 作废「不登录也能完整使用」这句旧承诺（App 侧）。

## 规格里的六条红线 → 我们要落成的门禁

规格已逐条给出「怎么判红」，实现时按这张表落地（`npm test` 结构门 + 断言）：

| 红线 | 规格给的判据 | 落成什么 |
|---|---|---|
| 1 · 未登录首屏只有登录 | 可点击元素 ⊆ {Apple, Google, 邮箱}；实心按钮 == 1；无「设置/复习/对话/字幕/文档」入口词 | App 壳结构门（扫 `#signed-out` 段与它的 paint 函数） |
| 2 · 屏序可达；屏 2 无跳过、屏 3 有跳过 | 冷启动 S1→S2→S3→Home 逐步可达；S2 不出现「跳过/稍后/先用着/skip」；S3 三态都有跳过且跳过后 `onboardingSeen = true` | 结构门 + 跳转断言 |
| 3 · 就绪判据 | 就绪函数可观测输入只有 `{isLoggedIn, engineResolvable, asrInstalled, ttsInstalled}`；**16 组布尔组合逐一断言**；扩展状态不得出现在签名/摘要/放行里 | 表驱动单测（真值表） |
| 4 · 两版同构 | cn / intl 全流程 **DOM 快照对比**：节点数、文案串、按钮顺序、状态分支数完全一致；允许差异白名单 = 出境同意条 · 额度来源行 · 引擎标识 | 快照门（两 flavor 渲染对比） |
| 5 · 旧承诺防复活 | 「不登录也能完整使用」一类不得再出现在 App 侧 | 文案 lint（含 12 语种） |
| 6 · 一屏一填色 + AA + 文案齐 | 每屏实心按钮 ≤ 1；对比度过 AA；新串 12 语种齐 | 现有 palette/对比度门 + i18n 门 |

## 已知的「还不是最终态」

- **体积 / 额度数字是占位**（规格里已标明），真值等实现时从注册表取。
- **只给了中文与英文文案**；12 语种由我们落。
- 这个 daemon 上**没有我们的 Organic 设计系统**（152 个里没有），所以品牌事实是以文字形式写进 brief 的 —— 已核验生成的 CSS 用了我们的九个 token（terra/sage/奶油/正文/危险 + Caprasimo + Figtree），没有另发明一套。
- 本目录**不含产品代码**：它是设计来源，落地走 `docs/interaction-spec.md` 与 `AGENTS.md` 规则 2/3 的修订，再由门禁与代码实现。
