# 大肚猴翻译 · 首屏与首次使用流程 — 品牌锁定

来源：任务书「品牌约束」一节（用户提供的品牌规范，优先级高于任何方向库）。

## OKLch token（值来自用户提供的 hex，不改写）

| token | hex | 用途 |
| --- | --- | --- |
| `--bg` | `#f5ead8` | 奶油底 |
| `--surface` | `#fff` | 面板白 |
| `--fg` | `#201e1d` | 正文 |
| `--muted` | `#6a655e` | 次级说明（在 #fff 上 5.7:1，在 #f5ead8 上 4.8:1） |
| `--terra-text` | `#96531f` | terra 浅底上的小字 / 文字链（在 #fff 与 terra 8% 底上均 ≥ 5.1:1） |
| `--border` | `#e2d6c1` | 分隔与描边 |
| `--accent` | `#c67139` | terra 品牌主色（描边、色块、图形） |
| `--accent-press` | `#ac6231` | 实心按钮底（白字 4.66:1，过 AA） |
| `--sage` | `#56633f` | 译文 / 成功 / 就绪 |
| `--sage-on` | `#728157` | 已开启（浅底深字） |
| `--danger` | `#b3261e` | 失败与危险 |

## 字体

- 展示：Caprasimo（仅拉丁）
- 正文：Figtree（仅拉丁）
- CJK：回落系统字 `"PingFang SC","Hiragino Sans GB","Noto Sans CJK SC","Microsoft YaHei"`

## 3–5 条观察到的规则

1. 实心（填色）按钮只用 `--accent-press`；terra `#c67139` 只用于描边、色块、进度与图形，不做实心底。
2. 三档圆角：指示性小元件 8 · 卡片与面板 16 · 可交互控件与图标胶囊 999。
3. 状态语义色：就绪/成功 = sage，失败 = danger，未就绪 = 灰化而非红色。
4. 图标线性、`stroke-width: 2.75`、圆头圆角端。
5. 单一动作一屏只允许一个实心按钮，其余为 outline / ghost / 文字链。

一句话：奶油底 + 面板白 + terra 描边体系，sage 表达「可用」、danger 只表达「失败」，信息层级靠留白与字重，不靠色块堆叠。
