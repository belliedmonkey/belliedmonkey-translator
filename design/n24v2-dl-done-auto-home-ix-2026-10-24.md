## 问题（现网）

下载全部就绪后仍停在语言包下载面，唯一出口是「进入实时听译」。用户想回到首页（对话·实时听译 / 实时字幕 / 今天待复习），只能被迫点进听译，或找不到回首页路径。

## 改法

### D-03 齐态出口

| 场景 | 规则 |
| --- | --- |
| **首启硬门**（登录后第一次下完语言包） | 下载全部就绪后 **自动 dismiss 下载面 → 进首页**（用户截图那一屏）。不停留「好了」页；不自动开听译会话。 |
| **补齐 / 设置·管理语言包**（从设置或听译「补回」进来） | 下完后 **自动回进入前的来源面**（设置或听译），不硬跳首页；若来源已关则进首页。 |
| 「好了」过渡 | **可要可不要**：若保留，最多短闪 ≤800ms（标题「好了」+ 进度满格），然后自动跳；**不要**再放唯一 CTA「进入实时听译」挡路。推荐：**不要单独「好了」页**，满进度后直接跳。 |
| 失败 / 部分失败 | 不自动跳；停在下载面，CTA「重试」或「继续下载」。 |
| 后台下完 | 用户若仍在下载面：回到前台且已齐 → 同上自动跳；用户若已离开下载面：不抢焦点弹首页，仅通知（若产品已有完成通知则沿用）。 |

### 不做

- 不自动进入听译会话 / 不自动「开始听译」。
- 不改硬门「没下完不进首页」。
- 不改 D-02 下载中进度（本补丁只动齐态出口）。
- 不在本补丁重开选语言 IA。

## 验收

- [ ] 首启：进度到 100% / 全部就绪后，无需点任何按钮即可看到首页三卡（对话·实时听译、实时字幕、今天待复习）。
- [ ] 首启下完后 **不会** 自动打开听译会话。
- [ ] 从设置「管理语言包」补下完后，回到设置（或来源），不误跳首页抢上下文。
- [ ] 失败态不自动跳。

## 文案锁影响

- 废弃齐态主 CTA「进入实时听译」作为唯一出口（质量 COPY-LOCK 若仍锁此句，需改：齐态无主 CTA，或仅作次要「打开听译」文字链——**推荐无 CTA、直接跳**）。
- 「好了」标题若保留短闪可不锁；若不做单独页则删除该文案依赖。
